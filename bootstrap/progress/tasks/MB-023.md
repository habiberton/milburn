## Decisions and blockers

- Negative refusal and failure tests must precede the happy path.
- The worker must not modify coordinator-owned planning or progress files.
- Accepted inputs are an optional leading `--verbose`, an optional `--` separator, then a nonempty command plus opaque arguments; `MILBURN_VERBOSE=1` selects the same direct-streaming path and other values retain quiet mode.
- Commands containing `/` must name an existing executable regular file; other command names must resolve through the shell command lookup. Missing names return 127 and non-executable paths return 126 before log or command effects.
- Quiet mode validates/creates the selected log directory and creates a unique log before the command. Verbose mode follows the existing `run-tests.sh` convention and `exec`s directly, preserving stdout, stderr, signals, and status without wrapper output or a log.
- Full quiet-mode stdout/stderr is intentionally combined in command order in one retained log; the success summary is the only terminal output, while failure adds exactly the last 40 log lines.
- Known unresolved limitations: MB-023-F001 is linked to #49 and MB-023-F002
